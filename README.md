# 📊 Customer Churn Analysis & Low-Level Image Processing

## 🔥 Overview
This project combines **Data Analysis** and **Low-Level Image Processing** concepts to demonstrate strong fundamentals in both domains.

- 📊 **Customer Churn Analysis**: Identifies key factors influencing customer churn in a telecom dataset.
- 🖼️ **Image Processing (Manual Implementation)**: Implements pixel-level transformations on BMP images **without using high-level libraries like OpenCV**.

---

## 🎯 Key Highlights

✅ Performed analysis on **7,000+ customer records**  
✅ Identified high-risk churn segments (e.g., senior citizens, monthly contracts)  
✅ Implemented **5 image transformations manually**  
✅ Worked at **binary file level (BMP format)**  
✅ No use of OpenCV — pure logic-based implementation  

---

## 📊 Customer Churn Analysis

### 📌 Dataset Insights
- Total Customers: **7043**
- Churn Rate: **~26.5%**

### 🔍 Key Findings
- 👴 Senior citizens have **~42% churn**
- 📄 Month-to-month contracts → **~43% churn**
- 💰 High monthly charges → **higher churn risk**
- 🌐 Fiber optic users → **highest churn (~42%)**
- 🔐 Customers with security & support → **lower churn**

### 💡 Business Recommendations
- Offer **long-term contract incentives**
- Improve **fiber service quality**
- Provide **early onboarding support**
- Promote **auto-pay methods**
- Bundle **security & tech support services**

## 🖼️ Image Processing (BMP - Manual)

### ⚙️ Features
- Read BMP image **byte-by-byte**
- Extract pixel values manually
- Apply transformations pixel-by-pixel
- Write output back to BMP format

### 🔄 Transformations Implemented
1. **Inverse Transformation**
2. **Log Transformation**
3. **Power (Gamma) Transformation**
4. **Linear Transformation**
5. **Point (Threshold) Transformation**
